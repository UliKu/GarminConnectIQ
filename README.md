# Garmin Connect IQ Experiments

This repository contains experimental code for private use based on the Garmin
Connect IQ platform. It is not an official Garmin project.

## Apps

- [Heart Beats per Kilometer](HeartbeatsPerKm/README.md)

## Build

Ensure Java is installed and available on `PATH` for the Connect IQ compiler.
Open the `HeartbeatsPerKm` folder as a Connect IQ project in VS Code with the
Monkey C extension, select the Forerunner 935 (`fr935`) as the target, and
build/run the project on the simulator or watch.
